⚡ Voltkit

Herramientas potentes para tu escritorio Linux: OCR de pantalla, un lector y creador de códigos QR, un selector de color, una regla de pantalla, un compresor de imágenes y videos, un expansor de texto, Mantener activo, un editor de hosts y entorno, Pegado inteligente, un buscador de “¿qué lo está usando?”, un administrador de permisos de apps, un diagnóstico de suspensión, un informe del sistema y un detective de atajos, en una app GTK4 nativa. En español, inglés y alemán.

Instalación

Para Ubuntu 24.04+, Debian 13+ y derivadas (Linux Mint 22, Zorin OS 18, Pop!_OS 24.04) en Intel/AMD de 64 bits:

sudo curl -fsSLo /usr/share/keyrings/voltkit-archive-keyring.gpg \
  https://arios4k.github.io/voltkit/voltkit-archive-keyring.gpg

echo "deb [signed-by=/usr/share/keyrings/voltkit-archive-keyring.gpg] https://arios4k.github.io/voltkit stable main" \
  | sudo tee /etc/apt/sources.list.d/voltkit.list

sudo apt update
sudo apt install voltkit

Las actualizaciones llegan con sudo apt upgrade.

Instalación en Fedora

Para Fedora 43 y posteriores en Intel/AMD de 64 bits, desde el repositorio COPR:

sudo dnf copr enable arios/voltkit
sudo dnf install voltkit

Configuración

Abre Voltkit desde tus apps. Eso es todo: inicia su servicio en segundo plano (que también se inicia en cada inicio de sesión) y, en GNOME, agrega sus atajos de teclado. voltkit doctor revisa que todo esté en orden.

Desinstalación

sudo apt remove voltkit
sudo rm /etc/apt/sources.list.d/voltkit.list /usr/share/keyrings/voltkit-archive-keyring.gpg

Código fuente, documentación y reportes: github.com/arios4k/voltkit. Los paquetes están firmados; la clave es voltkit-archive-keyring.gpg.
