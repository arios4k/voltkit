⚡ Voltkit

OCR, a color picker, an asset compressor and a text expander for Linux, in one app.

Install

For Ubuntu 24.04+, Debian 13+ and derivatives (Linux Mint 22, Zorin OS 18, Pop!_OS 24.04) on 64-bit Intel/AMD:

sudo curl -fsSLo /usr/share/keyrings/voltkit-archive-keyring.gpg \
  https://arios4k.github.io/voltkit/voltkit-archive-keyring.gpg

echo "deb [signed-by=/usr/share/keyrings/voltkit-archive-keyring.gpg] https://arios4k.github.io/voltkit stable main" \
  | sudo tee /etc/apt/sources.list.d/voltkit.list

sudo apt update
sudo apt install voltkit

Set up

voltkit doctor                    # check that everything is in place
voltkit shortcuts install         # GNOME: Super+Shift+T, C and E
voltkit daemon enable-autostart   # start the background service at login

Updates arrive with sudo apt upgrade.

Uninstall

sudo apt remove voltkit
sudo rm /etc/apt/sources.list.d/voltkit.list /usr/share/keyrings/voltkit-archive-keyring.gpg

Source, documentation and issues: github.com/arios4k/voltkit. Packages are signed; the key is voltkit-archive-keyring.gpg.
