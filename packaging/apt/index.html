⚡ Voltkit

Power tools for your Linux desktop: screen OCR, a QR code scanner and maker, a color picker, a screen ruler, an image & video compressor, a text expander, Keep Awake, a hosts & environment editor, Smart Paste, a “what's using this?” finder, an app permissions manager, a sleep troubleshooter, a system report and a shortcut detective, in one native GTK4 app.

Install

For Ubuntu 24.04+, Debian 13+ and derivatives (Linux Mint 22, Zorin OS 18, Pop!_OS 24.04) on 64-bit Intel/AMD:

sudo curl -fsSLo /usr/share/keyrings/voltkit-archive-keyring.gpg \
  https://arios4k.github.io/voltkit/voltkit-archive-keyring.gpg

echo "deb [signed-by=/usr/share/keyrings/voltkit-archive-keyring.gpg] https://arios4k.github.io/voltkit stable main" \
  | sudo tee /etc/apt/sources.list.d/voltkit.list

sudo apt update
sudo apt install voltkit

Updates arrive with sudo apt upgrade.

Install on Fedora

For Fedora 43 and newer on 64-bit Intel/AMD, from the COPR repository:

sudo dnf copr enable arios/voltkit
sudo dnf install voltkit

Set up

Open Voltkit from your apps. That's all: it starts its background service (which also starts at every login) and, on GNOME, adds its keyboard shortcuts. voltkit doctor checks that everything is in place.

Uninstall

sudo apt remove voltkit
sudo rm /etc/apt/sources.list.d/voltkit.list /usr/share/keyrings/voltkit-archive-keyring.gpg

Source, documentation and issues: github.com/arios4k/voltkit. Packages are signed; the key is voltkit-archive-keyring.gpg.
