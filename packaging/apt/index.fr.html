⚡ Voltkit

Des outils puissants pour votre bureau Linux : OCR d’écran, un lecteur et créateur de codes QR, un sélecteur de couleur, une règle d’écran, un compresseur d’images et de vidéos, un expanseur de texte, Rester éveillé, un éditeur de hosts et d’environnement, le collage intelligent, un détecteur de « qu’est-ce qui l’utilise ? », un gestionnaire d’autorisations des applications, un diagnostic de la veille, un rapport système et un détective de raccourcis, dans une application GTK4 native. En français, anglais, espagnol, allemand et chinois simplifié.

Installation

Pour Ubuntu 24.04+, Debian 13+ et dérivées (Linux Mint 22, Zorin OS 18, Pop!_OS 24.04) sur Intel/AMD 64 bits :

sudo curl -fsSLo /usr/share/keyrings/voltkit-archive-keyring.gpg \
  https://arios4k.github.io/voltkit/voltkit-archive-keyring.gpg

echo "deb [signed-by=/usr/share/keyrings/voltkit-archive-keyring.gpg] https://arios4k.github.io/voltkit stable main" \
  | sudo tee /etc/apt/sources.list.d/voltkit.list

sudo apt update
sudo apt install voltkit

Les mises à jour arrivent avec sudo apt upgrade.

Installation sous Fedora

Pour Fedora 43 et ultérieures sur Intel/AMD 64 bits, depuis le dépôt COPR :

sudo dnf copr enable arios/voltkit
sudo dnf install voltkit

Configuration

Ouvrez Voltkit depuis vos applications. C’est tout : il démarre son service en arrière-plan (qui démarre aussi à chaque ouverture de session) et, sous GNOME, ajoute ses raccourcis clavier. voltkit doctor vérifie que tout est en place.

Désinstallation

sudo apt remove voltkit
sudo rm /etc/apt/sources.list.d/voltkit.list /usr/share/keyrings/voltkit-archive-keyring.gpg

Lisez le manuel (en anglais) : chaque fonction, avec des captures.

Code source, documentation et signalements : github.com/arios4k/voltkit. Les paquets sont signés ; la clé est voltkit-archive-keyring.gpg.
