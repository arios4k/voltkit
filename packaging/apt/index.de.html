⚡ Voltkit

Praktische Werkzeuge für Ihren Linux-Desktop: Texterkennung, ein QR-Code-Scanner und -Generator, ein Farbwähler, ein Bildschirmlineal, ein Bild- und Videokompressor, Textbausteine, „Wach halten“, ein Editor für hosts und Umgebungsvariablen, „Intelligentes Einfügen“, eine Suche nach „Was belegt das?“, eine Verwaltung für App-Berechtigungen, eine Fehlersuche für die Bereitschaft, ein Systembericht und ein Tastenkürzel-Detektiv – in einer nativen GTK4-App. Auf Deutsch, Englisch, Spanisch, Französisch und vereinfachtem Chinesisch.

Installation

Für Ubuntu 24.04+, Debian 13+ und Abkömmlinge (Linux Mint 22, Zorin OS 18, Pop!_OS 24.04) auf 64-Bit-Intel/AMD:

sudo curl -fsSLo /usr/share/keyrings/voltkit-archive-keyring.gpg \
  https://arios4k.github.io/voltkit/voltkit-archive-keyring.gpg

echo "deb [signed-by=/usr/share/keyrings/voltkit-archive-keyring.gpg] https://arios4k.github.io/voltkit stable main" \
  | sudo tee /etc/apt/sources.list.d/voltkit.list

sudo apt update
sudo apt install voltkit

Aktualisierungen kommen mit sudo apt upgrade.

Installation unter Fedora

Für Fedora 43 und neuer auf 64-Bit-Intel/AMD, aus dem COPR-Repository:

sudo dnf copr enable arios/voltkit
sudo dnf install voltkit

Einrichtung

Öffnen Sie Voltkit aus Ihren Apps. Das ist alles: Es startet seinen Hintergrunddienst (der auch bei jeder Anmeldung startet) und fügt unter GNOME seine Tastenkürzel hinzu. voltkit doctor prüft, ob alles eingerichtet ist.

Deinstallation

sudo apt remove voltkit
sudo rm /etc/apt/sources.list.d/voltkit.list /usr/share/keyrings/voltkit-archive-keyring.gpg

Lies das Handbuch (auf Englisch): jede Funktion mit Screenshots.

Quellcode, Dokumentation und Fehlermeldungen: github.com/arios4k/voltkit. Die Pakete sind signiert; der Schlüssel ist voltkit-archive-keyring.gpg.
